# Personal Portfolio Website


A clean, responsive, and minimalist personal portfolio website built to showcase web development skills, education, completed courses, and projects. 

## 🚀 Demo
The layout features a multi-section single-page structure containing:
Home / Hero Section: Brief introduction and dynamic developer role description.
About Me: Personal summary and background details.
My Skills:Technical skill badges.
Projects:Grid layout showcasing completed work.
Education & Certifications: Academic timeline and certified course details.
Contact:Direct channels for communication and a functional footer.



🛠️ Built With

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom responsive layout design 


📱 Features

Fully Responsive:Adapts seamlessly across desktop, tablet, and mobile devices using a mobile-first CSS media query strategy .
Clean Typographic Hierarchy:Uses structured font variations to ensure readability.
Interactive Navigation:** Smooth hover states across navigation anchors and clear action triggers like the "Hire Me" button.
 Contains quickly scannability matrices for site navigation links and core contact information.
